The cron field is always visible so the saved value is always clear; the picker just makes common choices easy. Expects the Jinja2 context to have either `agent.schedule_cron` (edit page) or nothing (create page). Falls back gracefully in both cases. #} {%- set _sched = '' -%} {%- if schedule is defined and schedule -%} {%- set _sched = schedule -%} {%- elif agent is defined and agent.schedule_cron -%} {%- set _sched = agent.schedule_cron -%} {%- endif -%}
